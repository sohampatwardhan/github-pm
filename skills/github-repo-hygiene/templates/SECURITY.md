# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it through [private vulnerability reporting](https://github.com/OWNER/REPO/security/advisories/new). Include the version, the impact, and a way to reproduce the problem if you have one.

You should receive an acknowledgement within 3 business days. If private reporting is unavailable, contact the maintainers out of band and say so in the pull request that added this file.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| older | No |

Security fixes ship on a supported release line and are called out in the release notes.
